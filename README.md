# Viddie

**Turn an idea into an editable video.**

Viddie brings storyboarding, scene editing, narration, captions, and publishing into one video creation workflow.

![Viddie video editor showing the preview, timeline, and scene controls](docs/screenshots/video-edit.png)

- Draft a storyboard with AI or start with your own images, clips, and audio.
- Edit scenes, record or generate narration, and add captions, music, and transitions.
- Turn highlights from longer videos into portrait clips.
- Export landscape, portrait, or square videos and publish through connected accounts.

Development continues in a private repository. This repository is Viddie’s public showcase.
