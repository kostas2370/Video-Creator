# The one requirements file — used by the Docker image and by CI.
#
# Install it with the constraints file alongside, always:
#
#     PIP_CONSTRAINT=requirements/constraints.txt pip install -r requirements/requirements.txt
#
# constraints.txt stays separate because it is a different mechanism: it pins the torch
# stack across the whole resolution, transitive dependencies included, which a
# requirements file cannot do. Without it, coqui-tts/basicsr/facexlib/gfpgan quietly
# pull a CUDA build of torch over the CPU one and add ~2.5GB of nvidia-* packages.
